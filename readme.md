## What Was Included (Technical Breakdown)
To bring this project to life, I utilized several core HTML5 elements and concepts:

### 1. Document Boilerplate
* `<!DOCTYPE html>`: Declared the document type to ensure modern browser rendering.
* `<html>`, `<head>`, and `<body>`: Separated page metadata (like the `<title>`) from the visible content.

### 2. Text & Hierarchy
* **Headings (`<h1>` to `<h3>`):** Used to establish a clear visual hierarchy and organize different sections of the page.
* **Paragraphs (`<p>`) & Formatting (`<strong>`, `<em>`):** Structured the main body text and emphasized key points.

### 3. Media & Links
* **Hyperlinks (`<a href="...">`):** Connected my page to external websites and created smooth navigation.
* **Images (`<img src="..." alt="...">`):** Embedded visual content while practicing web accessibility by including descriptive `alt` text.

### 4. Lists & Containers
* **Lists (`<ul>`, `<ol>`, `<li>`):** Organized information cleanly using bullet points and numbered steps.
* **Semantic Tags (`<header>`, `<main>`, `<footer>`, `<section>`):** Grouped related content logically rather than relying solely on generic `<div>` tags.

## Challenges & What I Learned
* **File Paths:** Understanding how relative file paths work when linking local images.
* **Tag Nesting:** Making sure every opening tag had a properly placed closing tag so the layout wouldn't break.
* **Developer Tools:** Learned how to use the browser's "Inspect" tool to troubleshoot layout issues in real time.
